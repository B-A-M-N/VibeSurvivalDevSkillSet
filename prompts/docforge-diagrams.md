# DocForge Architecture Diagram Generation Prompt

## Architecture Diagram Creation
Generate multiple types of diagrams:
1. **Module Dependency Graph**: Show import relationships between modules
2. **Flow Charts**: Illustrate key workflows and processes
3. **State Machines**: Visualize state transitions for complex systems
4. **Class Hierarchies**: Display inheritance and composition relationships

## Output Formats
- **Mermaid**: For web-based documentation
- **PlantUML**: For detailed UML diagrams
- **SVG**: For static high-quality images
- **DOT**: For Graphviz processing

## Diagram Standards
- Clear module boundaries and interfaces
- Accurate dependency relationships
- Minimal crossing edges where possible
- Consistent styling across diagram types
- Legend for complex symbols

## Integration Points
- Auto-update on code structure changes
- Sync with API documentation
- Reflect actual module relationships
- Support incremental updates
