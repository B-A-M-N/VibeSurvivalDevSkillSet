# DocForge API Documentation Prompt

## API Reference Generation
Generate comprehensive API references by:
1. Parsing all function/method signatures
2. Extracting type annotations and return types
3. Cross-referencing with spec contracts
4. Documenting parameters with types and descriptions
5. Generating usage examples from code patterns

## Inline Docstring Generation
Update source code with proper docstrings:
1. Identify all public classes, methods, and functions
2. Apply consistent docstring format (Google/NumPy style)
3. Include parameter types, descriptions, and defaults
4. Document return values and raise conditions
5. Add examples where applicable
6. Preserve existing useful comments

## README Sections
Create/maintain README sections:
1. Quick start with current API highlights
2. Installation instructions reflecting current state
3. Basic usage examples from actual code
4. API overview with links to full references
5. Architecture overview with current diagrams

## Quality Standards
- Accuracy: Must match actual code behavior
- Completeness: All public interfaces documented
- Consistency: Format standards across all documents
- Validity: All examples must be executable
