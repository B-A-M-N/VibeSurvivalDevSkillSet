## Step-by-Step Instructions

### 1. Pattern Discovery
- Examine existing code files in the repository
- Identify recurring code structures and templates
- Document common class patterns, method signatures, and interfaces
- Extract style conventions and formatting rules

### 2. Naming Convention Analysis
- Document class naming patterns (PascalCase, snake_case, etc.)
- Extract method naming conventions and verb choices
- Note variable naming styles and scope indicators
- Identify prefix/suffix patterns for special types

### 3. Architecture Style Extraction
- Identify architectural patterns used (layers, modules, components)
- Document dependency direction and coupling patterns
- Extract common design pattern implementations
- Note interface and abstract class usage

### 4. Code Organization Patterns
- Document file structure conventions
- Extract import ordering and organization rules
- Identify common code blocks and their ordering
- Note documentation and comment patterns

### 5. Consistency Verification
- Verify pattern consistency across multiple files
- Identify exceptions and their justifications
- Document pattern variations for different contexts
- Prepare pattern mapping for implementation

### 6. Pattern Application Planning
- Map spec requirements to appropriate patterns
- Plan how to apply patterns to new code
- Identify when to extend vs. replicate patterns
- Prepare for pattern-based code generation

### 7. Implementation Guidelines
- Create pattern-based templates for new files
- Document pattern-specific rules and constraints
- Prepare examples of pattern application
- Set up validation checks for pattern compliance

### 8. Pattern Validation
- Verify new code follows documented patterns
- Check naming consistency across files
- Ensure architectural integrity is maintained
- Validate pattern adherence in integration
